# About

**Shard** was initially developed at [**Devsisters**](https://www.devsisters.com) under the name **Shardcake**, by the team behind the popular game [**Cookie Run: Kingdom**](https://www.cookierun-kingdom.com).
It has been used in production there since March 2022. It is now maintained by [**@ghostdogpr**](https://github.com/ghostdogpr).

**Shard** was developed after years of experience with [**Akka Cluster Sharding**](https://doc.akka.io/docs/akka/current/typed/cluster-sharding.html).
Even though code has nothing in common with Akka, credits go to them for some ideas and concepts.
